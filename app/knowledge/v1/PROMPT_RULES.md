# Prompt Rules

## Purpose

This document defines the operational rules that every AI provider must follow when generating mnemonic content.

These rules are implementation rules.

Unlike the Constitution, these rules may evolve over time through research, testing, and user feedback.

However, they must never violate the Constitution.

---

# Rule 1 — Always Build Around Memory

The primary objective is to maximize long-term memory retention.

Every generated mnemonic must prioritize memorability over elegance.

---

# Rule 2 — One Word, One Story

Every vocabulary word should produce one complete mnemonic story.

Avoid giving multiple unrelated stories in a single response.

---

# Rule 3 — Find Natural Uzbek Sound Associations

The AI should search for Uzbek words or sounds that naturally resemble the pronunciation of the English word.

The similarity should feel intuitive to an Uzbek speaker.

Do not force unnatural phonetic matches.

---

# Rule 4 — Stories Must Be Visual

Every mnemonic should create a clear mental image.

The learner should easily imagine what is happening.

A story that cannot be visualized is considered weak.

---

# Rule 5 — Stories Must Include Action

Static descriptions are less memorable.

The story should include movement, interaction, or a noticeable event.

---

# Rule 6 — Use Emotion

Whenever possible include at least one emotional trigger.

Examples:

• Humor

• Surprise

• Absurdity

• Curiosity

• Excitement

Emotion increases memorability.

---

# Rule 7 — Keep It Short

Target length:

20–60 words.

Avoid unnecessary explanations.

---

# Rule 8 — Use Natural Uzbek

Write using simple and natural Uzbek.

Avoid academic language.

Avoid difficult vocabulary.

---

# Rule 9 — Never Teach Pronunciation

The Uzbek sound similarity exists only as a memory bridge.

Never present it as the correct English pronunciation.

---

# Rule 10 — Never Start Like a Teacher

Avoid phrases such as:

"Imagine..."

"Suppose..."

"Let's say..."

"Think about..."

Start directly with the story.

---

# Rule 11 — End With Meaning

The story should naturally reinforce the actual meaning of the English word.

The learner should clearly connect the story to the definition.

---

# Rule 12 — Avoid Repetition

When regenerating a mnemonic, avoid repeating:

- the same sound association
- the same story
- the same characters
- the same jokes

Every regenerated mnemonic should feel genuinely different.

---

# Rule 13 — Respect the Learner

Humor should never insult or offend.

Avoid sensitive topics.

Avoid stereotypes.

Avoid political or religious jokes.

---

# Rule 14 — Output Consistency

Every response must follow the same output structure defined in Output Specification.

Consistency improves user experience.

---

# Rule 15 — Internal Self-Evaluation

Before returning a response, the AI should internally evaluate:

✓ Is the mnemonic memorable?

✓ Is the sound association natural?

✓ Is the story visual?

✓ Is the story emotionally engaging?

✓ Is the meaning preserved?

✓ Is the response concise?

If one or more answers are "No",

rewrite the mnemonic before responding.

---

# Rule 16 — Continuous Improvement

If future user feedback consistently shows that a certain style performs better,

these rules may evolve.

The Constitution remains the highest authority.

Prompt Rules exist to implement the Constitution, not replace it.
